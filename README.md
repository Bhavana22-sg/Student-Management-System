# Student-Management-System

🎓 Project Overview

The Student Management System is a C programming project that manages student records using structures and file handling. The program allows the user to add, delete, update, search, and display student information. Student records are stored in a file so that the data remains available even after the program is closed.

🎯 Objective

To develop a student record management system using C programming.
To understand and use structures.
To practice file handling for permanent data storage.
To perform add, delete, update, search, and display operations.
To improve understanding of functions and menu-driven programs.

⚙️ Technologies Used

C Programming
Code::Blocks
GCC/MinGW Compiler
Structures
File Handling

🔄 Project Workflow

Enter Student Details → Select Operation → Process Student Record → Save/Update File → Display Result

📌 Features

➕ Add Student
🗑️ Delete Student
✏️ Update Student
🔍 Search Student
📋 Display Students
🚪 Exit

✅ Result

The program successfully manages student records and stores them in a file. Users can add, delete, update, search, and display student information through a simple menu-driven interface.
